# 系统与当前状态

本项目围绕 STARFAB/Scout 农业机器人上的柔性杆索机械臂。已有代码分为三路弯曲电机与一路展开电机，通过两路串口总线交换 A1 协议报文。视觉提供被控点的三维位置及姿态。当前主控位置任务只优化 xyz，姿态是可选约束。

原始节点保留直接弯曲/展开与电机伺服实现，见 [原始快照](../reference/original_468fcfd39fa6/atarm_controller/arm_controller_node.py)。新增控制在其旁边独立实现，见 [三维控制核心](../atarm_controller/cartesian_control.py)。源文件的作者、历史接口和配置冲突均保留，不把新旧控制节点同时启动。

当前链路为外部 `PoseStamped` 与源状态配对，经固定外参变换和时效验证后进入三维任务层，再把三维虚拟输入转换成四路索长，最后通过原生 A1 协议读取实际编码器回复。ROS 回调仅受理目标/取消和发布缓存状态，单一所有者线程执行 I/O。

Mark 提出的优先顺序已落实到现场流程。先解决新供电与基本展开、保持、收回和小幅弯曲，再确认位置反馈、机械参考和初始 J，最后验证到指定三维位置。软件通过不能代替供电或承重保持已经通过。

目前关键缺口包括当前电源与停止/支撑条件、真实串口和电机映射、展开方向/增益/弯曲限值的历史分歧、真实视觉坐标和时钟、实测初始三维 J 及到位误差。当前四通道分配没有主动索张力闭环；展开时是否需要三路弯曲索共同收放，应在现场辨识后决定。
