# 三维闭环与逆运动学

“移动到指定位置”需要从目标位置计算输入。现有方法已经包含局部数值逆运动学，用视觉反馈反复修正，不必先实现完整解析逆运动学才能形成位置闭环。

令被控点位置为 p，目标为 p*，误差 e=p*−p。虚拟输入 u 包含两个弯曲坐标和一个伸缩坐标。局部模型为 Δp≈JΔu，J 为 3×3；四通道索长增量满足 Δq=MΔu，M 为 4×3，上部 3×2 是弯曲索混合矩阵，最后一行对应展开。实机的 M、初始 J 与有效局部范围仍需标定。

对当前候选输入集合 A，程序通过阻尼最小二乘计算 Δu_A=α(J_AᵀJ_A+λ²I)⁻¹J_Aᵀe，再根据四电机步长、绝对行程和模型范围缩放。实现位于 [candidates](../atarm_controller/cartesian_control.py) 与 [least_squares](../atarm_controller/cartesian_math.py)。

`alternating` 分别估算弯曲块和伸缩块，选择预计能降低误差的可行小步。`coordinated` 同时计算三个虚拟输入并分配到四通道。两者都在每个小步后等待电机稳定和新鲜视觉窗口，最后再次验证整体 xyz 目标。单个电机或子动作成功不代表任务完成。

在线更新使用前后稳定窗口的实际 Δq 反求 Δu，再以实际视觉 Δp 修正 J。程序对激励幅度、时间配对、方向一致性、更新幅度、秩与条件数作约束，拒绝冻结、回放或噪声主导的样本。FD 任务每个目标从本会话配置的初始 J 开始，目标内更新，不静默沿用上一任务学到的 J。

Mark 所说的“逆运动矩阵”可对应几何逆解、局部 J 的逆/伪逆或经验映射，具体含义仍应结合他的表达确认。几何模型可用于提供初值和可达域，视觉闭环负责纠偏，在线 J 更新修正局部输入输出关系，这几部分可以组合。

本方法当前验证到三维位置闭环。它没有提供任意六自由度位姿控制、完整全局规划或主动张力控制。模拟的亚毫米误差不能用作机械臂实测精度。
