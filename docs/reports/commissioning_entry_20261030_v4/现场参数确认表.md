## 2. 通信与设备身份，两个串口分别填

| 参数 | `site.ports.active` 与 `site.ports.deploy` 对应字段 | 确认方式 |
|---|---|---|
| 哪个适配器连接三路弯曲索，哪个连接展开索 | `by_id_path` | Mark 指认实物；你核对 `/dev/serial/by-id/` 稳定别名 |
| USB 序列号、厂商和产品编号 | `usb_serial`、`usb_vid`、`usb_pid` | 用实际 udev/sysfs 元数据与实物标识交叉核对，不能抄旧串口名 |
| 主臂 A1 的实际波特率 | `baud_rate` | 查已经成功的主臂配置及适配器/电机设置，必要时与 Mark 核对 | 
| 数据位、校验、停止位、流控 | `data_bits`、`parity`、`stop_bits`、`flow_control` | 确认是否确实为本入口支持的 8N1、无流控，不按猜测填写 |
| 半双工方向由谁控制 | `adapter_direction_control` | 需确认适配器自动处理；手动 RTS 等方式当前未实现 |
| 单次有效回复等待预算 | `reply_timeout_s` | 根据真实串口回复及控制预算测量；不能为消除超时任意增大 |
| 其他控制程序是否已经关闭 | `confirmations.sole_controller_owner` | 双方确认唯一控制进程；独占请求不能排除已持有串口的程序 |

不要使用 `/dev/ttyUSB0` 的临时序号充当设备身份。不同总线允许相同电机 ID，同一总线不允许重复。不要把末端 DYNAMIXEL 的 57600 设置当作主臂 A1 波特率。PTY 测试使用的 4,800,000 也不是现场推荐值。

## 3. 四台电机分别填写的机械与执行参数

`session.channels` 的顺序是 `[弯曲q1, 弯曲q2, 弯曲q3, 展开qe]`。前 3 路 bus 为 active，第 4 路为 deploy，其余安装参数都待确认。

| 字段 | 需要确认什么 | 主要工作 |
|---|---|---|
| `motor_id` | 总线上的实际 ID 与哪一根索对应 | Mark 指认，你逐路核对 |
| `direction` | 编码器正转对应索收紧还是放松，填 +1 或 -1 | 低速小幅实测；正索长在代码中表示收紧 |
| `radius_m` | 有效卷筒半径及绕索层数 | 你测量，Mark 确认索路；不默认采用源码中的 26 mm |
| `gear_ratio` | 型号对应的实际减速比与编码器位置定义 | 查电机/SDK约定，并用实测核对 |
| `encoder_reference_rad` | 指定机械参考形态下该电机的协议转子角 | 记录真实反馈，不能把上电时角度直接清零 |
| `length_reference_m` | 同一机械参考形态下的索长控制坐标 | 与 `controller.reference_lengths_m` 逐项一致 |
| `kp`、`kd` | 当前 A1 协议中的转子侧增益及安全适用载荷 | 用已确认方式逐级实测；不直接照抄旧输出侧增益 |
| `max_feedback_torque_nm` | 反馈力矩的单位、符号和允许界限 | Mark 与你确认；该值不等于索张力或总电流限值 |
| `max_temperature_c` | 实际允许温度及温度反馈可用性 | 按器件要求及现场试验确认 |

还要逐路填写 `controller.min_lengths_m`、`max_lengths_m`，确认机械余量与干涉边界。软件限制不能替代物理限位、支撑和观察。

## 4. 视觉、坐标与 ROS 参数

| 参数 | 配置字段 | 由谁完成与验证 |
|---|---|---|
| 哪台相机、安装位、控制相机光心还是工具尖端 | 相机证据、`camera_child`、`control_child` | 双方确认对象，你记录序列号与安装照片 |
| 定位输出的父坐标系与米制尺度 | `source_parent`、源状态 `metric` | 你用已知距离与方向独立检查，不只看轨迹形状 |
| 控制目标采用哪个基座/世界坐标系 | `target_parent` | 双方明确测量与使用的基准 |
| 地图会话与重建后的处理 | `map_epoch` | 你确认与源状态一致；地图变更后停机重建参考 |
| 地图到基座的刚体变换 | `base_from_source_translation`、`base_from_source_quaternion` | 你测量/标定，用独立检查点验证 |
| 相机到工具控制点的刚体变换 | `camera_from_control_translation`、`camera_from_control_quaternion` | 你标定；工具偏置会随相机姿态旋转 |
| 位姿及源状态实际话题 | `site.ros.pose_topic`、`source_status_topic` | 你确认消息类型与同时间戳配对，Mark 确认现场采集拓扑 |
| ROS_DOMAIN_ID、RMW 与控制命名空间 | `site.ros.domain_id`、`rmw_implementation`、`namespace` | 你核对现场 ROS2/DDS 连通性，避免接入错误控制域 |
| 源捕获时间与主机时钟关系、跨主机偏差 | 时钟与延迟证据、`confirmations.vision_and_clock` | 你实测确认；消息接收时间不等于曝光时间 |

变换采用 `T_a_b` 把 b 系坐标变到 a 系的约定，平移单位为米，四元数顺序为 `[x,y,z,w]` 且归一化。当前视觉最大年龄 150 ms、电机反馈最大接收年龄 100 ms 保留为软件策略；需要证明现场连续满足，不能只用平均帧率。A1 RX 时间也不等于已经测得设备内部采样年龄。

## 5. 三维模型、动作和到位判据

| 参数组 | 对应字段 | 现场要取得的依据 |
|---|---|---|
| 参考形态与四索参考 | `reference_lengths_m`、编码器参考 | 物理标记/独立测量、载荷、末端角度与相机安装记录 |
| 两弯曲量与展开量到四索的映射 | `cable_mix` | 实际索路、方向与张力需求；矩阵结构不适用时先修改模型，不能强行启动 |
| 初始三维雅可比及适用范围 | `initial_jacobian`、`max_model_radius_m` | 三个方向的实测扰动数据、独立组合扰动验证、回差/残差 |
| 秩与病态程度 | `min_singular_value`、`max_condition` | 实际坐标单位、奇异值与方向独立性，不能直接采用模拟门槛 |
| 索长速度、单步与最小可辨步长 | `speed_m_s`、`max_motor_step_m`、`min_step_m` | 供电能力、机械可控性和测量分辨率 |
| 总索长行程、迭代/时间预算 | `max_total_travel_m`、`max_steps`、`timeout_s` | 本轮允许动作范围与现场退出条件 |
| 相机可分辨噪声、位置容差、稳定窗口 | `camera_noise_bound_m`、`position_tolerance_m`、`stable_s`、`filter_frames` | 静止与运动试验、独立测量精度和任务需要；不默认 0.5 mm |
| 编码器到位与运动一致性 | `motor_tolerance_m`、`max_speed_m_s`、`pose_step_margin_m` | 实测编码器分辨率、真实最大端部速度与观测误差 |
| 动作后等待、轮询、无进展判据 | `settle_s`、`settle_timeout_s`、`poll_s`、`min_progress_m`、`no_progress_steps` | 实际机构稳定时间和视觉更新，不靠放宽阈值凑通过 |
| 更新规则与激励范围 | `learning_rate`、`min_learning_step_m`、`max_pair_s`、`max_update_fraction` | 在初始 J 小目标验证通过后，另行确认在线学习设置 |

首轮模板预选 `strategy=alternating`、`online_update=false`，先用冻结的实测 J 做小目标验证，再考虑同步协调与有界在线更新。其他已有算法参数也列在模板中供复核；物理配置要求显式给值，删除字段不会回退到模拟默认值。
